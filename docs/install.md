# Install

Download one file from the latest release. Open it, accept the one prompt, paste the key.

!!! warning

    Only someone you know. The button gives them a shell as `tunelito`.

## Windows

<a href="https://github.com/estcarisimo/tunelito/releases/latest/download/tunelito.exe">tunelito.exe</a>. Open it, accept the Windows screens, paste the key, press the button.

The page to send them: <a href="../es/guia/">Para vos</a>.

An installer exists and is optional. You do not need the Start menu.

## macOS

<a href="https://github.com/estcarisimo/tunelito/releases/latest/download/tunelito.dmg">tunelito.dmg</a>. Open it, drag Tunelito to Applications, open it, accept the one prompt.

## Debian

<a href="https://github.com/estcarisimo/tunelito/releases/latest/download/tunelito.deb">tunelito.deb</a> or <a href="https://github.com/estcarisimo/tunelito/releases/latest/download/tunelito.AppImage">tunelito.AppImage</a>. Install or run it, open Tunelito, accept the one prompt.

The first prompt installs OpenSSH if it is missing, creates the `tunelito` account (not an administrator), and does not start anything at boot.

## Then

Copy or share the address. Leave it on only while you want them connected. The timer defaults to 2 hours. Closing the window turns it off.
