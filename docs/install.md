# Install

This is the computer you want to reach. One file, one prompt, paste the key.

!!! warning

    Only someone you know. The button gives them a shell as `tunelito`.

## Windows

Download `tunelito.exe` and open it. Accept the one UAC prompt. Paste the key. Press the button.

An installer exists and is optional. You do not need the Start menu.

## macOS

Open the `.dmg` and drag Tunelito to Applications. Open it. Accept the one prompt.

## Debian

Install the `.deb`, or run the AppImage. Open Tunelito. Accept the one prompt (`pkexec` or `sudo`).

The first prompt installs OpenSSH if it is missing, creates the `tunelito` account (not an administrator), and does not start anything at boot.

## Then

Copy or share the address. Leave it on only while you want them connected. The timer defaults to 2 hours (15 minutes to 24 hours). Closing the window turns it off.
