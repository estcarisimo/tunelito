# For the person at the computer

Send them the Spanish page: <a href="../es/guia/">Para vos</a>.

Same steps, in English.

Someone they know is going to help with this computer and will send a key on WhatsApp. That is the whole task.

**If they do not know the person, they should not open anything.**

## 1. Download the file

It is named `tunelito.exe`.

![The file is named tunelito.exe](images/guia-archivo.png){ width="280" }

## 2. Open it

Double-click. There is no installer. A window opens.

If Windows says it protected the PC, the file is not signed yet. It is not broken. Click **More info** (**Más información**), then **Run anyway** (**Ejecutar de todas formas**).

![Windows protected your PC. Click More info](images/guia-smartscreen.png){ width="520" }

![Then click Run anyway](images/guia-smartscreen-2.png){ width="520" }

Windows asks whether to allow changes. Click **Yes** (**Sí**). Once.

![Click Yes](images/guia-uac.png){ width="520" }

## 3. Paste the key

Copy the whole WhatsApp message. It starts with `ssh-ed25519`.

Paste it in the big field.

![The key pasted into Tunelito](images/guia-pegar.png){ width="520" }

## 4. Turn it on

Press **Turn on**. Confirm once.

![Confirm](images/guia-encender.png){ width="360" }

## 5. Send the address back

An address ending in `trycloudflare.com` appears. Press **Copy** or **Share** and send it on WhatsApp, to the same person.

![Copy or share the address](images/guia-direccion.png){ width="520" }

The address alone lets nobody in. The key they pasted is what allows it.

## 6. Turn it off

Press **Turn off**, under Copy. Closing the window also turns it off. If nobody does, it turns off after two hours.

Opening the app again does not turn it back on.
